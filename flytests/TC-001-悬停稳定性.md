# TC-001 悬停稳定性

| 项 | 内容 |
|---|---|
| 编号 | TC-001 |
| 前置条件 | PX4 SITL，机型 sihsim_quadx（SYS_AUTOSTART=10040），GPS 正常 |
| 步骤 | 1. 启动 SITL　2. `commander takeoff` 起飞至默认高度　3. 保持定点悬停 ≥ 20 s　4. `commander land` 降落　5. 导出 .ulg 日志 |
| 数据来源 | `vehicle_attitude`（姿态）、`vehicle_local_position`（高度/垂直速度）、`actuator_motors`（油门）、`sensor_combined`（角速度）、系统消息 |
| 判读工具 | `pytools/ulog_report.py`（人读报告）／ `flytests/test_tc001_hover_stability.py`（机器判定） |

## 预期结果（量化判据）

| # | 判据 | 阈值 | 对应用例 |
|---|---|---|---|
| 1 | 悬停段 roll / pitch 幅度 | ≤ ±1° | `test_roll_stability` / `test_pitch_stability` |
| 2 | 悬停段高度漂移 | ≤ 0.5 m | `test_altitude_hold` |
| 3 | 悬停油门均值 | 45% ~ 55% | TC-002 `test_throttle_in_range` |
| 4 | 角速度峰值 | ≤ 30 °/s | TC-003 `test_gyro_peak` |
| 5 | 系统消息 | 无 ERROR | TC-004 `test_no_error_messages` |
| 前置 | 存在可判读悬停段 | ≥3 s | `test_hover_segment_exists` |
