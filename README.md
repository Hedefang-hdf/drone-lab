# drone-lab · 无人机测试实验室

> 用软件测试的方法学无人机：SITL 实验、飞行测试用例、日志判读工具、自动化报告。

这是一个无人机测试工程师的成长实验室。我把七年软件测试的工程习惯——用例化、工具化、自动化、报告化——应用到了无人机领域：**每一次仿真飞行都有测试用例，每一条飞行日志都有体检报告，每一个判读标准都写成了断言。**

## 这个仓库里有什么

| 目录 | 内容 |
|---|---|
| [`pytools/`](pytools/) | Python 工具集：日志体检报告、SITL 自动化 |
| [`gotools/`](gotools/) | Go 工具：ulog → HTML 报告站（规划中） |
| [`flytests/`](flytests/) | 飞行测试用例库：悬停稳定性等，日志断言 = 飞行回归测试 |
| [`docs/`](docs/) | 学习笔记：SITL 搭建踩坑、PID 原理、日志判读 |
| [`data/`](data/) | 真实飞行日志样例（PX4 SITL 悬停） |
| [`reports/`](reports/) | 工具生成的报告输出（不入库） |

## 快速开始

```bash
# 依赖
pip install pyulog pytest

# 给一条飞行日志出体检报告
make report ULOG=data/20261027-sitl-hover.ulg

# 跑飞行测试用例（里程碑 M2）
make test
```

报告会对悬停质量做逐项判定：

| 检查项 | 判定标准 | 依据 |
|---|---|---|
| 姿态稳定性 | 悬停段 roll/pitch 在 ±1° 以内 | 正常悬停姿态扰动量级 |
| 高度保持 | 高度漂移 < ±0.5 m | 定点悬停典型值 |
| 悬停油门 | 45% ~ 55% | 50% 留一半余量给抗风与机动 |
| 振动水平 | 角速度峰值 < 30°/s | 排除异常振动/震荡 |
| 系统消息 | 无 ERROR 级日志 | 飞控运行期故障零容忍 |

## 里程碑

- [x] **M1** 仓库初始化：日志体检工具 `ulog_report.py` + 真实样例日志
- [ ] **M2** 飞行测试用例库：`pytest` 断言悬停判读标准 → **飞行的回归测试**
- [ ] **M3** Go 工具 `ulog2html`：一条命令把 .ulg 转成可读的 HTML 报告站
- [ ] **M4** SITL 自动化流水线：MAVSDK-Python 脚本自动起飞 → 悬停 → 降落 → 取日志 → 自动判读，一条命令从仿真到报告

## 学习路线（ docs/ 里同步记录）

1. **PX4 SITL 仿真环境** — 编译、机型配置、QGC 联调
2. **日志与数据分析** — .ulg 结构、pyulog、判读标准、PlotJuggler
3. **控制原理** — PID 四环串级（位置 → 速度 → 姿态 → 角速度）
4. **飞行测试用例设计** — 从需求到用例到判读到报告闭环
5. **自动化** — MAVSDK 脚本化飞行测试

## 环境说明

样例日志来自 PX4 SITL 仿真（`PX4_SIM_MODEL=sihsim_quadx`，36 秒定点悬停），非实飞数据；判读阈值参考 PX4 飞行复查（Flight Review）的公开标准做了简化，供学习交流使用。
