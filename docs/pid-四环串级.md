# PID 与四环串级：无人机怎么被"扶稳"的

## 三个字母各管什么

- **P（比例）**：管"快慢"。误差越大、修正越猛。P 太小反应迟钝，太大来回震荡。
- **I（积分）**：管"准头"。把累积的小误差慢慢补掉（比如持续侧风导致的缓慢漂移）。I 太大会"记仇"，过冲。
- **D（微分）**：管"稳重"。误差变化快的时候提前踩刹车，抑制超调。D 对噪声敏感，不能给太大。

## 为什么要多环：四环串级

无人机不是一组 PID 搞定的，而是四个环层层嵌套，**外环的输出是内环的目标值**：

```
位置环（想去哪）        输出：期望速度
   ↓
速度环（飞多快）        输出：期望姿态角
   ↓
姿态环（机头朝哪）      输出：期望角速度
   ↓
角速度环（转多快）      输出：电机指令
```

为什么这样设计？内环必须比外环"更勤快"：
角速度环以几百 Hz 运行，位置环只以几十 Hz 运行。
外环给出宏观目标，内环负责精细执行——就像领导定方向、员工抠细节。

## 测试视角：怎么从日志看出 PID 的问题

| 日志现象 | 可能原因 | 先查哪个环 |
|---|---|---|
| 高频小幅震荡（抖动） | 角速度环 P 过大 / 振动 | 角速度环 |
| 低频大幅摇摆 | 姿态环 P 过大 | 姿态环 |
| 缓慢漂移不回正 | I 不足 / I 饱和 | 位置/速度环 |
| 指令响应迟钝、软 | P 普遍偏小 | 各环 |
| 修正过头来回荡 | D 不足 / P 偏大 | 姿态/角速度环 |

PX4 参数对应：MC_ROLL_P（姿态环）、MC_ROLLRATE_P（角速度环）等，
`changed_parameters` 在 ulog 里可以直接查到改过的参数。
