## 怎么读

**先看图，再看字。** 每一节都是图打头。

在 VS Code 里打开 `01-从零认识无人机.md`，按 `Cmd+Shift+V`（Windows `Ctrl+Shift+V`）直接预览，**不用装任何插件**。图片是相对路径引用的本地 SVG，预览和 GitHub 网页上都能正常显示。

## 关于配图格式

用 **Markdown + 独立 SVG**，不用内嵌 Mermaid、也不用 PNG：

- SVG 是纯文本，能在编辑器里直接改一个字的颜色，改完即生效
- 几 KB 一个文件，仓库不会变重
- GitHub 原生渲染，VS Code 原生预览，**两边都零依赖**

PNG 是二进制，改一处都得重画；Mermaid 在 GitHub 上能渲染，但 VS Code 不装插件看不了 —— 而这份文档的主要使用场景恰恰是本地用 VS Code 学。
